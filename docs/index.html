sway-lang

Each Sway window keeps the keyboard layout you last used there. Come back, and the keys are already in that language.

A new window starts on the first layout in your Sway config. An empty workspace does too. For us,ua, that first layout is English.

What you see

Focus a window in the desk above. Its key lights. Press the other key and only that window changes. Leave for the empty workspace and the keyboard returns to English. The window you left still remembers Ukrainian.

What the daemon does

Sway owns the keymap. You keep xkb_layout and Super+Space. sway-lang listens on the Sway socket and, when focus moves, runs xkb_switch_layout for type:keyboard.

  1. You change the layout. The focused window stores that index.
  2. You focus a window you have used. Its index comes back.
  3. You focus a new window, or no window at all. Index 0 comes back.

Run it

cargo build --release
./target/release/sway-lang

The program reads SWAYSOCK. That path contains Sway’s pid, so a systemd user service must import the variable after Sway starts, then restart. The unit file in the repository is not installed for you.
