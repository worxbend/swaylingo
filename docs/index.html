Overview

sway-lang is a small Linux daemon for Sway. It watches focus and the active XKB layout. With xkb_layout us,ua, index 0 is English and index 1 is Ukrainian. Super+Space still switches. The daemon puts the saved index back when a window gains focus.

  1. 01

    A used window comes back as you left it.

    Notes on Ukrainian, mail on English. Focus notes again and the keyboard is Ukrainian. No extra key.

  2. 02

    A new window starts on layout 0.

    Open a terminal beside a Ukrainian window. The new one starts in English, the first name in your xkb_layout list.

  3. 03

    An empty workspace is layout 0 too.

    Switch to a workspace with nothing focused and the keyboard returns to English. The window you left still remembers Ukrainian.

Not per tab.

Firefox is one Sway window. Its tabs share a layout.

Not an input method.

English and Ukrainian here are XKB layouts, not fcitx or ibus.

Not saved to disk.

Window ids die when Sway exits. The map starts empty next time.

Install

Linux amd64 and arm64. The script checks the checksum, copies the binary to ~/.local/bin, and writes a user unit. It does not start the service. SWAYSOCK has to exist first.
